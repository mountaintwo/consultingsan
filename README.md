🎓 농어촌/기회균형 입시 컨설팅 솔루션 (Admission Consulting DB)
이 프로젝트는 입시 컨설턴트, 교사 및 수험생들이 주요 대학의 농어촌 및 기회균형 전형 인원 변동 사항을 한눈에 파악하고 검색할 수 있도록 제작된 단일 페이지 웹 어플리케이션(SPA)입니다.
---
🌟 주요 기능 (Features)
🔍 실시간 대학 검색: 검색창에 대학명(예: "서울대", "연세대")을 입력하면 즉시 결과가 필터링됩니다.
📑 전형별 탭 필터링: 전체보기, 교과 전형, 종합 전형, 정시 전형 탭을 클릭하여 원하는 전형 타입만 모아볼 수 있습니다.
📈 직관적인 증감 표시: 작년 대비 인원 변동(증가/감소/변동없음)이 직관적인 색상 뱃지(초록색/빨간색)로 표시됩니다.
💡 특이사항 요약: 수능최저학력기준 변경, 전형 신설/폐지 등 주요 참고 사항이 파란색 정보 박스로 강조되어 제공됩니다.
📊 요약 대시보드: 현재 등록된 데이터의 전형별(교과/종합/정시) 총 모집 인원을 상단에서 즉시 확인할 수 있습니다.
---
🛠 기술 스택 (Tech Stack)
이 어플리케이션은 복잡한 서버나 빌드 과정 없이 웹 브라우저만 있으면 실행되도록 설계되었습니다.
UI 라이브러리: React.js 18 (CDN)
스타일링: Tailwind CSS (CDN)
컴파일러: Babel Standalone (브라우저 내에서 JSX 변환)
폰트: Noto Sans KR (구글 폰트)
---
🚀 실행 방법 (How to Run)
별도의 설치나 환경 구성이 필요하지 않습니다.
다운로드 받은 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등의 웹 브라우저에서 엽니다.
(선택 사항) 웹 호스팅 서비스(GitHub Pages, Vercel, Netlify 등)에 `index.html` 파일을 업로드하면 누구나 인터넷을 통해 접속할 수 있습니다.

📝 데이터 업데이트 가이드 (Data Management)
해가 바뀌어 새로운 입시 데이터를 업데이트해야 할 경우, `index.html` 파일 내부의 `rawData` 배열을 수정하시면 됩니다. 파일의 `<script type="text/babel">` 바로 아래에 위치해 있습니다.
데이터 구조 (JSON)
각 대학의 데이터는 다음과 같은 객체 형태로 입력됩니다:
```javascript
{ 
    univ: "대학명", // 예: "서울대"
    g_name: "교과 전형명", // 없으면 빈 문자열 ""
    g_change: "작년→올해(교과)", 
    g_count: "올해 총원(교과)", 
    g_diff: "증감 수치(교과)", // 증가면 양수, 감소면 음수 문자열
    j_name: "종합 전형명", 
    j_change: "작년→올해(종합)", 
    j_count: "올해 총원(종합)", 
    j_diff: "증감 수치(종합)", 
    s_name: "정시 전형명", 
    s_change: "작년→올해(정시)", 
    s_count: "올해 총원(정시)", 
    s_diff: "증감 수치(정시)", 
    note: "특이사항 기재" // 없으면 빈 문자열 ""
}
```
수정 팁:
해당 전형이 없는 경우 `_name`, `_change`, `_count`, `_diff` 값을 모두 빈 문자열 `""`로 두시면 화면에 표시되지 않습니다.
`_diff` 값은 숫자로 된 문자열로 입력해야 우측 상단의 증감 뱃지가 정상적으로 계산되어 표시됩니다. (예: `"5"`, `"-3"`, `"0"`)
---
⚠️ 유의 사항
본 어플리케이션은 CDN 리소스를 사용하므로 실행 시 인터넷 연결이 필수입니다.
데이터베이스 서버가 없는 클라이언트 사이드 앱이므로, 데이터 수정은 반드시 `index.html` 소스코드 내에서 직접 이루어져야 합니다.
